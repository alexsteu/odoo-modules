How it works

1. Install the module.

There is nothing to set up.

2. Open the CRM in list view.

The column Age (days) shows the number of days since the opportunity was created.

3. Spot the old ones.

An age above 30 days is highlighted.

Settings

Nothing to configure. To hide the column, use the column picker at the top right of the list.

Good to know

  • The age is counted from the day the opportunity was created, not from the last activity.
  • The 30-day limit for the highlight is fixed.
  • The column is in the list view only, not on the kanban cards.
  • In the list, Odoo cuts the title of the column to “Age (da…” because number columns are narrow.
