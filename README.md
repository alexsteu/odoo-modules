# Odoo modules

Free Odoo modules for SMEs by Alexandre Gabriel (https://alexandregabriel.ch).

- `sale_quote_followup`: automatic e-mail reminder for unanswered quotations (Odoo 17).
- `account_invoice_overdue_reminder`: automatic e-mail for overdue customer invoices, for Odoo Community (Odoo 17).
- `crm_stale_opportunity_reminder`: to-do for opportunities nobody touched for X days (Odoo 17).
