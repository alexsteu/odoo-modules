VAT Number Required on Company Invoices

No more B2B invoices sent back for a missing VAT number

  • When you post a customer invoice or credit note for a company, Odoo checks it has a Tax ID / VAT number.
  • If missing, posting is blocked with a clear message telling which contact to fix.
  • Invoices to individuals are not affected.
