A quotation whose expiration date is past. The banner says: “This quotation has expired: its validity date is past. Update the prices and the date before sending or confirming it.” The button Fill with AI comes from another module of this suite. Demo data, shown in the Odoo 18 version.

How it works

1. Install the module.

There is nothing to set up.

2. Open a quotation.

If its Expiration date is past, the red banner is shown at the top.

3. Update the quotation.

Change the prices, set a new expiration date and save. The banner is no longer shown.

Settings

Nothing to configure.

Good to know

  • It is a warning only. It does not block sending or confirming.
  • The banner is shown on quotations, draft or sent. Not on confirmed orders.

Upgrading from version 17.0.1.0.x

Replace the code, then upgrade on the command line, before anyone signs in, all the modules of this suite that are installed, in one go:

odoo-bin -d <database> -u <module>,<module> --stop-after-init

Three modules of the suite add fields to contacts and companies. Until they are upgraded, Odoo refuses the sign-in.
