How it works

1. Open a contact.

It needs a mobile number, or at least a phone number.

2. Click Open WhatsApp chat.

The link is next to the Mobile field.

3. Write your message in WhatsApp.

WhatsApp opens on that number. You write and send the message yourself.

Settings

Nothing to configure, and no API key.

Good to know

  • It is a plain link to WhatsApp. Odoo does not send or store any message.
  • The mobile number is used first, then the phone number.
  • A number without country code is completed with the country of the contact, or else of your company. Without any country, no link is shown.
