WhatsApp Button on Contacts

Chat with your customers on WhatsApp in one click

  • Adds a WhatsApp link under the phone number of every contact.
  • Uses the mobile number, or the phone number if there is no mobile.
  • Works with international numbers (+41, +33, 0041...). The link only appears when the number is in international format.
  • No configuration, no API key.
