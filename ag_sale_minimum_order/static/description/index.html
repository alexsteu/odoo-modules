Minimum Order Amount

Stop accepting orders that cost you more than they earn

  • Set a minimum untaxed amount in Sales > Configuration > Settings.
  • Quotations below this amount cannot be confirmed; the user gets a clear message.
  • 0 = no minimum. Applies to orders in the company currency.
